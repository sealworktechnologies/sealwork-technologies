# Sealwork Technologies website

A responsive, premium one-page website for a rubber moulding manufacturer. Built with plain HTML, CSS and JavaScript; no build tools required.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example `sealwork-technologies`).
2. Upload `index.html`, `style.css`, `script.js` and the `assets` folder.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. GitHub will show your live website URL.

## Important before publishing
- In `index.html`, replace `YOUR-GITHUB-USERNAME` and `YOUR-REPOSITORY` in the canonical URL, Open Graph URL/image and JSON-LD URL with your real GitHub Pages address. If you connect a custom domain, use that domain instead.
- Add your real factory/company address, product photos, certifications and verified manufacturing capabilities if you want them displayed. This starter intentionally avoids inventing these details.
- The enquiry form opens the visitor's default email app (mailto); it does not store submissions. For a hosted form that sends enquiries without opening email, connect a form service or backend.
- The popup appears once per browser session. Phone and email links are already configured.
- Google Fonts are loaded online; the site otherwise works as a static website.

## SEO notes
The page includes a descriptive title, meta description, crawl directives, canonical URL placeholder, Open Graph tags, semantic headings, mobile layout and ManufacturingBusiness structured data. Replace the URL placeholders before launch. Add Google Search Console and submit the live URL/sitemap after deployment.
